## 2024-05-24 - Cryptographic Vulnerability in crypto.createCipher
**Vulnerability:** The application was using the deprecated `crypto.createCipher` function in `lib/security.ts` to encrypt sensitive data. This function automatically derives a key from the password, but the derivation method is considered insecure and the function is deprecated in modern Node.js versions.
**Learning:** When updating cryptographic functions from `crypto.createCipher`/`crypto.createDecipher` to `crypto.createCipheriv`/`crypto.createDecipheriv`, ensure that an explicit Initialization Vector (IV) is provided and that a fallback mechanism is implemented during decryption to maintain backward compatibility for previously encrypted data. The `createCipheriv` requires exactly 32 bytes for the `aes-256-gcm` key, which is already correctly established in the codebase using `crypto.scryptSync`.
**Prevention:** Always use `crypto.createCipheriv` and `crypto.createDecipheriv` with explicitly generated secure Initialization Vectors (IVs) and proper key derivation methods rather than relying on the deprecated functions' implicit and insecure key derivation.
