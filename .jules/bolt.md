## 2023-11-20 - Sequential Promise Bottleneck in Performance Endpoint
**Learning:** Found a severe sequential bottleneck in `computeAllFarmers` in `pages/api/v1/farmers/performance.ts` where we fetch data for each farmer in a `for...of` loop, triggering 4 DB queries sequentially per farmer. This O(n) blocking behavior severely impacts overall request latency as `N` scales. However, unbounded concurrency using raw `Promise.all` can cause database connection pool exhaustion if `N` is large.
**Action:** Replaced sequential `for...of` await with a chunked `Promise.all` approach to fetch data concurrently while capping the maximum number of concurrent database queries. Always scan list-aggregating endpoints for sequential `await` patterns inside loops, and use chunking or batching when parallelizing to prevent resource exhaustion.
